# {{PLAYBOOK_TITLE}}

> Real stories from {{YOUR_NAME}}'s work in {{FIELD}}. Not theory, not frameworks, the actual hidden work that never makes it into official guidance.

This repo is the source of truth for a practitioner playbook project: a running capture of real, specific stories from doing {{FIELD}} work, turned into (1) a future book/guide and (2) a weekly LinkedIn content engine that builds an audience before launch.

## What this is

- **`stories/`** — one markdown file per real story, captured as it happens
- **`teaser-posts/`** — LinkedIn posts generated from those stories
- **`chapters/`** — playbook chapter drafts, once you have enough stories to group
- **`resources/`** — templates and setup guides (start with `resources/SETUP_GUIDE.md`)
- **`CLAUDE.md`** — the project charter Claude Code reads automatically when you work in this folder

## Quick start

New here? Read `resources/SETUP_GUIDE.md` first. It takes about 30 minutes end to end: clone this repo, fill in your details, set up two automated weekly routines, and capture your first story.

## The core idea

Most guidance in any field is generic. What actually helps practitioners is the hidden stuff: the thing standard guidance never mentions, the decision nobody prepared you for, the assumption that turned out wrong. This project captures those moments as they happen, in your own words, and turns the strongest ones into both a long-term book and short-term LinkedIn content, automatically.
